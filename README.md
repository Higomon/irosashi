# いろさし

日本語 · [English](README.en.md)

<br>

**つまようじアート・ドット絵の下絵を生成するWebアプリ。**

- 色を塗った爪楊枝を、スタイロフォーム等に挿して作るアート作品向け
- 写真をドット絵に変換し、色番号付きの下絵・材料表・印刷用PDFを生成

<br>

## [いろさしを使う →](https://higomon.github.io/irosashi/)

- **iPhone・パソコン対応／インストール不要**
- 仕上がり寸法・色数の調整
- **大きな下絵のA4分割印刷**
- 写真の処理は端末内で完結

<br>

## 使用例

| 元の画像 | 下絵の仕上がり |
| --- | --- |
| ![家と太陽のお試し画像](docs/examples/original.png) | ![200mm四方の下絵](docs/examples/pattern.png) |

- 仕上がり：200 × 200 mm
- 爪楊枝の中心間隔：5 mm／40列 × 40行
- 使用色：7色

<br>

### 色番号付きの下絵

- 各マスに使用色の番号
- 材料表・図案・配置図のPDF出力

<br>

![色番号付きの下絵](docs/examples/layout.png)

<br>

### A4分割印刷

- **400 × 400 mmの下絵 → A4縦4枚**
- 配置：2列 × 2行／余白：5 mm
- 図案4枚＋材料表／別PDFの配置図

<br>

| A4に分割した4枚 | 貼り合わせ後 |
| --- | --- |
| ![A4縦4枚への分割](docs/examples/a4-pages.png) | ![番号順に貼り合わせた下絵](docs/examples/a4-assembled.png) |

<br>

1. 用紙「A4」→「分割を見る」
2. PDFを保存 → **実際のサイズ（100%）で印刷**
3. 白い余白の切り取り
4. 番号順に配置 → **紙を重ねず、端同士で貼り合わせ**

<br>

## 使い方

1. 写真の選択（[お試し画像](docs/examples/sample.png)）
2. 寸法・爪楊枝の間隔・色数の調整
3. 用紙・余白・分割の確認
4. PDFの保存・印刷
5. 下絵に沿って、色を塗った爪楊枝をフォーム材へ挿入

- 爪楊枝の直径・中心間隔：実測値を入力
- iPhoneのPDF保存：「共有して保存」→「ファイルに保存」

<br>
