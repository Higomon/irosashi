# いろさし

写真から、色番号付きの図案と印刷用PDFを作るブラウザアプリです。

**iPhoneでも使えます。アプリのインストールは不要。Safariで開いて、写真を選ぶだけで始められます。**

**使う:** https://higomon.github.io/irosashi/

写真を選び、仕上がりを調整して、印刷用PDFを保存します。
写真の処理はブラウザ内で行います。

## iPhoneで、写真選びからPDF保存まで

- 写真ライブラリから画像を選び、仕上がりの寸法・色数を調整できます。
- 数値欄は数字キーボードに対応し、全角数字も入力確定時に半角へ変換します。
- 印刷用PDFは「共有して保存」から、共有画面の「ファイルに保存」で保存できます。
- パソコンでも、同じURLから使えます。写真の処理は端末のブラウザ内で行います。

### 色番号を見ながら作れます

各マスの番号が使う色を表します。印刷時には、材料表と図案のPDF、配置図のPDFを保存できます。
以下は色番号付き図案のプレビューです。

![40列×40行の色番号付き図案](docs/examples/layout.png)

この例の設定：仕上がり **200 × 200 mm**、串の中心間隔 **5 mm**、**40列 × 40行**。
色数は「8色まで」に設定し、変換結果は **7色** になりました。

### 大きな図案も、A4に分けて印刷できます

**A4プリンターで、大きな図案を分割印刷。余白を切り、番号順に並べて貼り合わせれば完成です。**

同じ家の画像を **400 × 400 mm** にした例です。
用紙を **A4**、余白を **5 mm** にすると、図案は **縦向き4枚（2列 × 2行）** に分割されます。
以下はアプリで生成した分割プレビューです。

| A4に分割した4枚 | 余白を切って貼り合わせた完成図 |
| --- | --- |
| ![400mm四方の図案をA4縦4枚に分割。左上001、右上002、左下003、右下004](docs/examples/a4-pages.png) | ![001から004の図案を2列2行に貼り合わせた400mm四方の完成図](docs/examples/a4-assembled.png) |

1. 「印刷する」で用紙に **A4** を選び、「分割を見る」で枚数と並びを確認します。
2. PDFを保存し、**実際のサイズ（100%）** で印刷します。「用紙に合わせる」などの拡大縮小は使いません。
3. 図案の外周に沿って白い余白を切り、**001 → 002、次の行は003 → 004** の順に並べます。
4. **紙は重ねず、端同士を合わせて**貼り合わせます。別PDFの配置図でも並びを確認できます。

図案PDFには、分割した図案に加えて先頭にA4の材料表が入ります。
上の「4枚」は図案部分の枚数です。実際の分割枚数は寸法・串の間隔・余白によって変わります。

### 同じ画像で試す

1. [お試し画像を開いて保存](docs/examples/sample.png)します。
2. [いろさしを開き](https://higomon.github.io/irosashi/)、「写真を選ぶ」から保存した画像を読み込みます。
3. 「仕上がりを決める」で寸法・串の間隔・色数を調整します。
4. 「印刷する」で用紙・余白・分割を確認し、PDFを保存します。

串の直径と中心間隔は、実際に使う材料を測って入力してください。

## 編集・更新

`いろさし - 図案を作る.html` が唯一の編集元です。
ダウンロードしてブラウザで開いても使えます。

`main` ブランチへのpushでGitHub ActionsがこのHTMLを一時的に
`index.html` として配置し、GitHub Pagesへ公開します。
公開用の別HTMLを管理する必要はありません。
